# NIRÆ Motion

Dalamud plugin repository for NIRÆ Motion (prototype, friends only).

Install: in game `/xlsettings` → Experimental → Custom Plugin Repositories → add

    https://raw.githubusercontent.com/urimusha/nirae-motion/main/repo.json

tick it, Save, then `/xlplugins` → All Plugins → "NIRÆ Motion" → Install, and `/nmotion`.

What it does: replaces the game's jiggle on the NIRÆ body with its own flesh physics, and lets hands and forearms
dent the skin. Everything happens only on your own screen.

Needs Penumbra and the NIRÆ Body mod. The skin dents also need the "NIRAE Shader Test" mod with its option set to
"Dents", placed above the body in priority, and the body on Build & Hips "Curvy · Medium hips". A Physics option
ending in "No collision" works best with the dents.
